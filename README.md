# Mônica Psicologia — projeto demonstrativo de portfólio

Site one-page desenvolvido em React + TypeScript + Tailwind CSS, usando como referência a estrutura de `saude/saude.tsx` e componentes do conjunto de templates fornecido.

## Importante: conteúdo fictício
Mônica é uma personagem fictícia. Formação, instituição de ensino, endereço, horários e condições de atendimento são ilustrativos. Não existe CRP atribuído. O formulário apenas demonstra a interação e não envia nem armazena dados. Não usar os dados como informações reais.

## Executar localmente
1. Instale Node.js (versão LTS).
2. Na pasta do projeto, execute `npm install`.
3. Execute `npm run dev` e abra o endereço local informado pelo Vite.
4. Para validar a compilação, execute `npm run build`.
