# Footer1
Ideal para sites corporativos que precisam apresentar informações institucionais, produtos, links úteis e dados de contato em um único espaço.

A faixa superior com redes sociais facilita o acesso aos canais da empresa, enquanto as quatro colunas organizam as informações de maneira clara. Utilize cores contrastantes para separar a área principal da faixa de copyright.

Esse modelo é indicado para empresas, prestadores de serviços, lojas virtuais e plataformas digitais que possuem várias informações para disponibilizar ao visitante.

# Footer2
Recomendado para sites que possuem muitas categorias de navegação e desejam destacar uma ação adicional, como cadastro ou inscrição.

A estrutura com cinco colunas permite distribuir conteúdos diferentes, mantendo uma organização visual consistente. A área de cadastro e a seção de redes sociais ficam separadas por divisórias horizontais, facilitando a identificação de cada bloco.

É uma boa opção para portais, plataformas digitais, empresas de tecnologia e sites comerciais. O botão de cadastro deve ser utilizado somente quando essa ação fizer sentido para o objetivo do site.

# Footer3

Ideal para sites que buscam um rodapé mais simples, elegante e centralizado, sem muitas colunas ou informações distribuídas lateralmente.

A navegação superior apresenta os principais links, enquanto a descrição institucional e os ícones das redes sociais ficam centralizados. A faixa inferior destaca as informações de copyright sem competir visualmente com o restante do conteúdo.

Esse modelo combina com sites institucionais, portfólios, páginas de apresentação e marcas que valorizam uma identidade visual minimalista. Utilize uma cor de fundo alinhada à identidade da empresa e mantenha espaçamentos equilibrados para preservar a simplicidade do layout.
